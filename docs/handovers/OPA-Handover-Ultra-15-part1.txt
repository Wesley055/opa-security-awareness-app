## 1. Working method

No file access. Manual command-and-paste: one command, the user runs it in

A parallel session with file access has existed. **If two run at once, only ONE

### Every command must carry its own control

**A command whose interesting result is a zero or an absence must also print a
number proving it reached real data.** `count=`, `files=`, `scanned=`, `lines=`.
`probe=` before everything.

```powershell
"probe=unique-token"; <rest of command>
```

**This rule caught three false negatives this session** and its absence caused
one. It is the most load-bearing habit in this project.

- `lines=0` revealed a read issued from the wrong working directory - `cd`
  persists between commands, and a relative path silently resolves against
  wherever you were last.
- `scanned=116` and `hits=14` overturned a conclusion that emergency
  intelligence had no consumers. **Without the control, `hits=0` from a broken
  glob looked exactly like a real absence.** Trap #83.
- `scanned=10, hits=0` **proved** the background capability is absent - a
  trustworthy zero, because the file count showed the sweep reached everything.

### Paste damage, and how to recover

- **The first line gets dropped**, silently, often. Never anchor on line 1.
- **The MIDDLE can drop.** A `git diff` arrived missing its header and first two
  hunks with later hunks intact.
- **The console echo appears ABOVE the probe.** Not a dropped line.
- **A whole previous console block can be pasted back** and PowerShell tries to
  execute each line. Harmless noise; read past it.

**The recovery that works: do NOT re-issue the same dump. Issue a NARROWER,
line-numbered read of exactly the missing facts.**

```powershell
$p='path\to\file.ts'; "probe=read lines=$((Get-Content -LiteralPath $p).Count)"; $n=0; Get-Content -LiteralPath $p | ForEach-Object { $n++; if ($_ -match 'PATTERN|PATTERN2') { "$n|$_" } }
```

**Multi-window reads work and save round trips:**
```powershell
$p='docs\TODO.md'; "probe=x lines=$((Get-Content -LiteralPath $p).Count)"; $n=0; Get-Content -LiteralPath $p | ForEach-Object { $n++; if (($n -ge 10 -and $n -le 30) -or ($n -ge 100 -and $n -le 120)) { "$n|$_" } }
```
